# Productivity App — Creating New Habits

An experimental web app exploring productivity, accountability, and habit-building.

## Project overview

This repository contains an HTML-based application prototype focused on encouraging more intentional daily habits. It is a work in progress.

## Explore the prototype

1. Download or clone this repository.
2. Open `App-with-Accountability (1).html` in a web browser.
3. Explore the prototype locally.

No deployment or automated test setup is documented yet.
